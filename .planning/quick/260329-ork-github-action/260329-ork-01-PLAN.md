<task type="auto">
  <name>Task 2: Create Release workflow</name>
  <files>.github/workflows/release.yml</files>
  <action>
Create `.github/workflows/release.yml` that triggers on:
- Push of tags matching 'v*' (e.g., v0.1.0)

Jobs:
1. create-release:
       - Run on ubuntu-latest
       - Create GitHub Release using softprops/action-gh-release@v2
       - Extract version from tag (strip 'v' prefix)

2. build-release:
       - Strategy: matrix with targets:
         - x86_64-unknown-linux-gnu (ubuntu-latest)
         - x86_64-apple-darwin (macos-latest)
         - aarch64-apple-darwin (macos-latest)
         - x86_64-pc-windows-msvc (windows-latest)
       - Use dtolnay/rust-action@stable with specified target
       - Run: cargo build --release --target ${{ matrix.target }}
       - Package binary:
         - Linux/macOS: tar czf openlist-tui-${{ matrix.target }}.tar.gz -C target/${{ matrix.target }}/release openlist-tui
         - Windows: 7z a openlist-tui-${{ matrix.target }}.zip target/${{ matrix.target }}/release/openlist-tui.exe
       - Upload to release using softprops/action-gh-release@v2

Use Swatinem/rust-cache@v2 for caching.
Set proper permissions: contents: write for release creation.
  </action>
  <verify>
    <automated>cat .github/workflows/release.yml | grep -q "softprops/action-gh-release" && cat .github/workflows/release.yml | grep -q "x86_64-unknown-linux-gnu" && cat .github/workflows/release.yml | grep -q "aarch64-apple-darwin"</automated>
  </verify>
  <done>Release workflow exists with multi-platform builds and automatic GitHub release creation</done>
